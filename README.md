# Economic & Financial Mod - Tradução PT-BR

![Victoria 3](https://img.shields.io/badge/Victoria%203-Compatible-green)
![Version](https://img.shields.io/badge/version-1.0-blue)

Tradução completa para Português Brasileiro do mod **Economic & Financial** para Victoria 3.

## 📋 Sobre

Este mod adiciona a tradução completa em português brasileiro para o [Economic & Financial Mod](https://steamcommunity.com/sharedfiles/filedetails/?id=3143591632), que transforma o Victoria 3 em uma verdadeira simulação de gestão econômica e financeira.

## ✨ Características

- ✅ **Tradução 100% completa** de todos os textos do jogo
- ✅ **18 arquivos de localização** traduzidos
- ✅ **60+ moedas** com nomes traduzidos
- ✅ **Ícones e texturas** funcionando corretamente
- ✅ **Codificação UTF-8 com BOM** para caracteres especiais
- ✅ **Compatível** com a versão mais recente do mod original

## 📦 O que foi traduzido

### Sistemas Principais
- 🏛️ **Interface completa**: Menus Economia, Finanças, Estoque
- 💰 **Sistema monetário**: Padrão-ouro, prata, bimetálico, fiduciário
- 📊 **Indicadores econômicos**: Inflação, valor da moeda, oferta monetária
- 🏦 **Sistema bancário**: Banco central, bancos privados, reservas
- 📈 **Mercado financeiro**: Bolsa de valores, produtos financeiros
- 💵 **Moedas do mundo**: Real Brasileiro, Dólar, Euro, Libra, etc.

## 🚀 Instalação

### Via Steam Workshop (Recomendado)
1. Inscreva-se no [Economic & Financial Mod](https://steamcommunity.com/sharedfiles/filedetails/?id=3143591632) original
2. Inscreva-se nesta tradução PT-BR
3. Ative ambos os mods no launcher do Victoria 3
4. **Importante**: A tradução deve ser carregada DEPOIS do mod original

### Manual
1. Baixe a [última release](../../releases)
2. Extraia a pasta `Economic&Financial PT-BR` para:
   - Windows: `%USERPROFILE%\Documents\Paradox Interactive\Victoria 3\mod\`
   - Linux: `~/.local/share/Paradox Interactive/Victoria 3/mod/`
   - Mac: `~/Documents/Paradox Interactive/Victoria 3/mod/`
3. Ative o mod no launcher do Victoria 3

## ⚙️ Configuração

No launcher do Victoria 3, certifique-se de que a ordem de carregamento está correta:

```
1. Economic & Financial Mod (ID: 3143591632)
2. Economic & Financial PT-BR ← Esta tradução
```
